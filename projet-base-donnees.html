MySQL MCD / MLD Data Analysis

Base de données sur la qualité de l'air

Ce projet consiste à concevoir et implémenter une base de données relationnelle MySQL permettant de stocker, structurer et analyser des relevés de qualité de l'air dans différentes régions géographiques.

Fonctionnalités principales

  • Stockage structuré des données de qualité de l'air avec MySQL.
  • Requêtes SQL avancées pour l'analyse statistique.
  • Optimisation de la BDD pour accélérer les consultations.
  • Modélisation complète via MCD et MLD.
